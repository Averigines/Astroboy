# Astroboy

## Description

Astroboy is a game about an astronaut needing to repair his rocket. \
The game was done for the Creative Code Lab of the fourth term in the bachelor studies 'Creative Computing'. The project was done in a 2-week timeframe in a 3-person team using Unity.

## Gameplay

- Collect repair parts for your rocket
- Pay attention to your oxygen - Don't stay outside for too long
- Explore the planet and your rocket and discover small secrets

## Controls

- WASD to move
- Spacebar to jump
- E to collect repair parts and interact with the terminal
